# E-Commerce Sales & Customer Intelligence Analysis

## Project Overview

This project analyzes e-commerce sales and customer data to identify
sales trends, profitable products, customer segments, regional performance,
profit risks, and business opportunities.

The objective is to transform raw e-commerce data into meaningful
business insights and actionable recommendations.

## Objectives

- Analyze overall sales and profit performance
- Identify high-performing product categories
- Analyze customer segments
- Compare regional performance
- Identify top and bottom performing products
- Analyze the relationship between discounts and profit
- Identify loss-making orders
- Generate actionable business recommendations

## Dataset

The project uses an e-commerce sales dataset containing information about:

- Orders
- Customers
- Customer segments
- Countries and regions
- Product categories
- Products
- Quantity
- Unit price
- Discounts
- Sales
- Shipping costs
- Profit
- Payment methods

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
